# Pousada Santo Inácio

Sistema web institucional com reserva rápida via WhatsApp para a Pousada Santo Inácio, em Taperoá - PB.

## Recursos

- Frontend em React com rotas para Início, Quartos, Sobre e Contato.
- Backend Node.js/Express apenas para API simples de informações e quartos.
- Sem MySQL, sem banco de dados e sem armazenamento de reservas.
- Todos os quartos configurados como disponíveis.
- Formulário que gera mensagem formatada e abre `https://wa.me/5583998710819`.
- Layout responsivo com foco em celular.
